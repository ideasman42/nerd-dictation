📦 Complete Installation

Step 1: Install Dependencies

# Install Python 3 (if not already installed) brew install python3 # Install VOSK API pip3 install vosk # Install PulseAudio (for audio capture) brew install pulseaudio

Step 2: Clone Repository

cd ~/SOCA/PROJECTS git clone https://github.com/ideasman42/nerd-dictation.git cd nerd-dictation

Step 3: Download Full Language Models

💡 Pro Tip: Use full models for 95%+ accuracy. Small models are only ~60-70% accurate.
# Create models directory mkdir -p ~/.local/share/vosk-models cd ~/.local/share/vosk-models # Download English model (~1.8GB) curl -L -o vosk-model-en-us-0.22.zip \ https://alphacephei.com/vosk/models/vosk-model-en-us-0.22.zip unzip vosk-model-en-us-0.22.zip # Download French model (~1.4GB) curl -L -o vosk-model-fr-0.22.zip \ https://alphacephei.com/vosk/models/vosk-model-fr-0.22.zip unzip vosk-model-fr-0.22.zip # Clean up zip files (optional - saves 3.2GB) rm *.zip

Step 4: Create Launch Scripts

# Create config directory mkdir -p ~/.config/nerd-dictation # Create French dictation script cat > ~/.config/nerd-dictation/vosk-fr.sh << 'EOF' #!/bin/bash MODEL_DIR="$HOME/.local/share/vosk-models/vosk-model-fr-0.22" cd "$HOME/SOCA/PROJECTS/nerd-dictation" ./nerd-dictation begin --vosk-model-dir="$MODEL_DIR" --punctuate-from-previous-timeout 2.0 EOF # Create English dictation script cat > ~/.config/nerd-dictation/vosk-en.sh << 'EOF' #!/bin/bash MODEL_DIR="$HOME/.local/share/vosk-models/vosk-model-en-us-0.22" cd "$HOME/SOCA/PROJECTS/nerd-dictation" ./nerd-dictation begin --vosk-model-dir="$MODEL_DIR" --punctuate-from-previous-timeout 2.0 EOF # Create stop script cat > ~/.config/nerd-dictation/vosk-end.sh << 'EOF' #!/bin/bash cd "$HOME/SOCA/PROJECTS/nerd-dictation" ./nerd-dictation end EOF # Make scripts executable chmod +x ~/.config/nerd-dictation/*.sh

Step 5: Test Installation

# Test French dictation ~/.config/nerd-dictation/vosk-fr.sh # Speak: "Bonjour, ceci est un test." ~/.config/nerd-dictation/vosk-end.sh # Test English dictation ~/.config/nerd-dictation/vosk-en.sh # Speak: "Hello, this is a test." ~/.config/nerd-dictation/vosk-end.sh

🌊 SOCA Pulse Optimization Methodology

📘 What is SOCA Pulse?
SOCA Pulse is an iterative, feedback-driven approach to optimizing voice-coding workflows. It emphasizes continuous refinement, context-aware dictation, and fail-closed validation.

Core Principles

🔄

Iterative Refinement

Start with basic dictation, analyze errors, refine pronunciation and context, repeat. Each cycle improves accuracy.

Continuous Improvement
🎯

Context-Aware Dictation

Use domain-specific vocabulary. Train the model with technical terms, code patterns, and project-specific jargon.

Domain Adaptation
🛡️

Fail-Closed Validation

Always verify output. If dictation fails or produces errors, stop and correct immediately rather than continuing.

Quality First
📊

Metrics & Feedback

Track accuracy rates, common errors, and time saved. Use data to guide optimization efforts.

Data-Driven

SOCA Pulse Workflow for Voice Coding

Phase 1: Baseline Assessment

  1. Test Baseline Accuracy
    • Dictate 100 words of typical code comments
    • Measure Word Error Rate (WER)
    • Identify common error patterns
  2. Analyze Failure Modes
    • Technical terms (e.g., "PostgreSQL", "kubectl")
    • Code syntax (e.g., "dot then" vs. ".then")
    • Punctuation patterns

Phase 2: Custom Vocabulary

💡 Pro Tip: Create a custom configuration file to transform technical terms and code patterns.
# ~/.config/nerd-dictation/nerd-dictation.py import re def nerd_dictation_process(text): """Custom post-processing for technical dictation""" # Technical term corrections replacements = { "postgres sequel": "PostgreSQL", "kube control": "kubectl", "docker compose": "docker-compose", "git hub": "GitHub", "versus code": "VS Code", "type script": "TypeScript", "java script": "JavaScript", "react jay ess": "React.js", "node jay ess": "Node.js", } text_lower = text.lower() for pattern, replacement in replacements.items(): text_lower = text_lower.replace(pattern, replacement) # Code pattern transformations text_lower = re.sub(r'\bdot\s+([a-z]+)\b', r'.\1', text_lower) # "dot then" → ".then" text_lower = re.sub(r'\barrow function\b', '->', text_lower) text_lower = re.sub(r'\bequals equals\b', '==', text_lower) text_lower = re.sub(r'\btriple equals\b', '===', text_lower) return text_lower

Phase 3: Speaking Techniques

  • Clear Pronunciation: Articulate technical terms slowly
  • Chunk Content: Speak in logical units (one function signature, one comment)
  • Pause Strategy: Use natural pauses (2 sec timeout configured)
  • Microphone Position: 15-20cm from mouth, avoid breath noise
  • Ambient Noise: Minimize background noise for best results

Phase 4: Workflow Integration

Use Case Recommended Approach Expected Accuracy
📝 Code Comments Dictate full sentences, review 95%+
📄 Documentation Dictate paragraphs, light editing 98%+
🐛 Commit Messages Short dictation, verify before commit 95%+
💬 Code Review Comments Natural speech, minimal editing 97%+
⚙️ Variable Names Use camelCase pronunciation 85%+
🔧 Code Blocks Hybrid: dictate + manual typing 70-80%

Phase 5: Continuous Refinement

  1. Daily Log: Track errors and patterns in a notebook
  2. Weekly Review: Update custom vocabulary based on logs
  3. Monthly Metrics: Calculate WER, time saved, satisfaction
  4. Quarterly Optimization: Major config updates, model upgrades

🚀 Advanced Optimization Tips

Performance Tuning

1. Adjust Timeout Settings

# Faster timeout for short bursts (e.g., variable names) --punctuate-from-previous-timeout 1.0 # Longer timeout for continuous dictation (e.g., documentation) --punctuate-from-previous-timeout 3.0

2. Suspend/Resume for Faster Startup

# Start dictation nerd-dictation begin --vosk-model-dir=~/.local/share/vosk-models/vosk-model-en-us-0.22 # Suspend when not in use (keeps model in memory) nerd-dictation suspend # Resume instantly (no reload time) nerd-dictation resume

3. Output to STDOUT (for preprocessing)

# Capture dictation output, process, then paste nerd-dictation begin --output=STDOUT | your-custom-processor | pbcopy

🔧 Troubleshooting

Common Issues & Solutions

❌ "parec command not found"

brew install pulseaudio

❌ No text appears when speaking

  • Check microphone permissions: System Settings → Privacy & Security → Microphone
  • Verify Terminal/iTerm is allowed to use microphone
  • Test microphone in another app (Voice Memos)
  • Check if dictation process is running: ps aux | grep nerd-dictation

❌ Poor accuracy / Wrong words

  • Upgrade to full models (not small models)
  • Speak more clearly and at normal pace
  • Position microphone closer (15-20cm)
  • Reduce background noise
  • Create custom configuration for technical terms

❌ Wrong language detected

  • Use language-specific scripts (vosk-fr.sh vs vosk-en.sh)
  • Don't mix languages in one session
  • Stop and restart when switching languages

❌ Keyboard shortcuts not working

  • Check System Settings → Keyboard → Keyboard Shortcuts → Services
  • Ensure Automator has Accessibility permissions
  • Verify Quick Actions are saved in ~/Library/Services/
  • Try logging out and back in

❌ High CPU usage

  • Normal: Full models are CPU-intensive during active dictation
  • Use suspend/resume instead of stopping/starting repeatedly
  • Close other resource-heavy applications
  • Consider using small models for low-priority tasks
